# MOGRT Subtitle Importer (통합 패널 버전)

Premiere Pro 내부에서 직접 **SRT 자막 파일**을 불러오고, 각 자막에 **MOGRT**를 적용하여 **타임라인에 자동 배치**해 주는 통합 확장 패널입니다.

## 🛠 1. 설치 방법

1. `CEP_MogrtImporter` 폴더(이 폴더 전체)를 복사합니다.
2. 아래의 경로로 이동하여 붙여넣기 합니다.
   * **Windows:** `%APPDATA%\Adobe\CEP\extensions\` 또는 `C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\`
   * **Mac:** `/Library/Application Support/Adobe/CEP/extensions/`
3. (필수) 서명되지 않은 확장을 허용하기 위해 **디버그 모드**를 활성화해야 합니다.
   * **Windows:** 레지스트리 편집기(`regedit`)를 열고 `HKEY_CURRENT_USER\Software\Adobe\CSXS.11` (또는 CSXS.10, CSXS.12 등 사용 중인 버전)으로 이동하여, `PlayerDebugMode` (문자열 값)을 생성하고 값을 `1`로 설정합니다.
   * **Mac:** 터미널에서 `defaults write com.adobe.CSXS.11 PlayerDebugMode 1` 입력 (버전 숫자는 맞춰서 변경)

**업데이트할 때 주의**: 프리셋과 작업 목록은 설치 폴더 안의 `cache` 폴더에 있습니다. 폴더를 지우고 새로 깔면 모두 사라집니다. 코드 파일만 덮어써 주세요.

## 🚀 2. 사용 방법 (화자 한 명)

1. Premiere Pro를 재시작합니다.
2. 상단 메뉴에서 **Window -> Extensions -> MOGRT Subtitle Importer** 를 클릭하여 패널을 엽니다.
3. 작업할 시퀀스를 엽니다. (시퀀스가 열려 있지 않으면 SRT를 열 수 없습니다. 목록은 시퀀스마다 따로 저장됩니다.)
4. 상단 툴바에서 **[📂 SRT 열기]** 버튼을 눌러 Premiere Pro에서 추출한 `.srt` 파일을 엽니다.
5. 리스트에 나타난 각 자막의 우측 드롭다운에서 적용할 프리셋을 선택합니다.
   * 프리셋을 고르면 아래에 세부 파라미터를 조절할 수 있는 창이 열립니다.
   * **T** 표시한 텍스트 필드에 자막 문장이 들어갑니다. 나머지 텍스트 필드(포인트 텍스트 등)는 후반 작업으로 직접 넣습니다.
   * 텍스트 필드마다 **T1·T2…** 번호가 붙습니다. 번호를 누르면 `#12 T2` 같은 주소가 복사되어 AI에게 요청할 때 쓸 수 있습니다.
6. 우측 상단 툴바에서 자막을 배치할 트랙(예: V3, V4)을 선택합니다.
7. **[▶ 타임라인에 적용]** 버튼을 누르면 타임라인에 자동으로 배치됩니다.

### 캡션을 고친 뒤 다시 가져오기

* Premiere에서 캡션을 고치고 SRT를 다시 내보낸 뒤 **[📂 SRT 열기]**로 같은 파일을 열면 **[병합]**을 고를 수 있습니다. 문장과 시간만 바뀌고 포인트 텍스트 등 후반 작업 값은 그대로 남습니다.
* 병합한 뒤 ▶를 누르면 **[안전하게 적용]**을 권합니다. 바뀐 줄만 한 줄씩 고칩니다.
* 되돌릴 일이 생기면 히스토리(🕘) 드롭다운의 **안전 지점**에서 가져오기 전 상태로 돌아갈 수 있습니다.

## 👥 3. 여러 화자 자막

1. Premiere에서 음성 분석으로 캡션을 만든 뒤, **화자마다 캡션 트랙을 하나씩** 나눕니다.
2. 캡션 트랙마다 SRT를 내보내며 파일 이름에 **캡션 트랙 번호**를 넣습니다. 예: `C1.srt`, `인터뷰_C2.srt`.
3. **[📂 SRT 열기]**에서 파일 여러 개를 한 번에 고릅니다. **SRT 가져오기** 창에서 화자 이름과 기본 프리셋을 정하고 [가져오기]를 누릅니다.
4. 목록 위 **화자 표**에서 화자마다 이름·트랙·기본 프리셋을 바꿀 수 있습니다. 화자 칩을 누르면 그 화자 줄만 보입니다.
5. **[▶ 타임라인에 적용]**: 첫 화자는 고른 기본 트랙에, 다음 화자는 그 위 빈 트랙(없으면 새로 만듦)에 놓입니다. 같은 시각에 두 사람이 말해도 트랙이 달라 자막이 잘리지 않습니다.
   * 확인할 것이 있으면 **적용 전 점검** 창이 뜹니다. (Premiere에서 고친 클립은 기본으로 건너뜁니다.)
   * 진행 중에는 [중지]로 멈출 수 있고, 다시 ▶를 누르면 이어서 진행합니다.
6. **[검수]**: 타임라인을 읽기만 해서 빠진 클립·옮겨진 클립·중복·Premiere에서 고친 클립을 보여 줍니다. 항목을 누르면 그 자리로 이동합니다.
7. **마지막 적용 되돌리기**: 히스토리 드롭다운 맨 위 **↶ 마지막 적용 되돌리기**로 타임라인만 되돌립니다. 적용 뒤에 고친 클립은 건드리지 않습니다.
8. 화자의 SRT를 다시 내보내면 화자 표에 알림이 뜹니다. **⟳**를 누르면 그 화자만 병합합니다.

### AI 제안

* Codex·Claude 같은 AI가 포인트 텍스트 등 후반 작업 값을 제안하면, 줄 속성창에 **AI 제안** 상자가 뜹니다. **[적용]**을 누르기 전에는 아무것도 바뀌지 않습니다.

## ⚠️ 주의사항
* **Premiere에서 만든 MOGRT**는 스크립트로 텍스트를 쓸 수 없어서, 문구를 넣은 템플릿 사본을 만들어 배치합니다. 줄마다 프로젝트의 'Motion Graphics Template Media' 빈에 항목이 하나씩 생깁니다.
* 타임라인에 MOGRT를 자동 배치하는 과정은 다소 시간이 걸릴 수 있습니다(클립 하나에 0.2~0.8초). 진행되는 동안 Premiere Pro를 조작하지 마세요.
* Premiere에 대화상자(예: 메모리 부족 경고)가 떠 있으면 패널이 멈춥니다. 대화상자를 닫으면 이어서 진행합니다.
