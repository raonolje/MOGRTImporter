# Stage-0 spike results — Premiere 26.5.1, 2026-09-24 (test project MOGRT_probe.prproj, PROBE_SEQ 1920x1080 @ 23.976 fps)

Probes ran through the production panel's CSInterface ($.evalFile of JSX files). Numbers refer to the A-final §17 spike list.

| # | Item | Result | Design consequence |
|---|---|---|---|
| 1 | `TrackItem.name` write (clip tag) | Works on AE MOGRT clips AND native (Premiere-made) Graphic clips. Survives: MGT text setValue, `end` change, project save, close/reopen, full Premiere restart. The project item name is NOT changed (only the track item). | Tag branch "T" is viable: tag = clip name, e.g. `철수 [MI:<uid>.<gen>]`. |
| 1b | Razor (QE `track.razor`) | Both halves keep the SAME name/tag. Original half keeps its nodeId, new half gets a new nodeId. | Duplicate-tag state must be detected (two clips same tag) and never auto-resolved. |
| 2 | `TrackItem.nodeId` | Exists (e.g. `000f4246`); identical after save/close/reopen/restart; changes only for the new half after razor. | nodeId usable as a secondary identity check. |
| 3 | `qe seq.addTracks(n, numVideoTracks, 0)` | Appends n video tracks AFTER the last one (existing numbering unchanged); no audio track added. | Auto-adding speaker tracks at the top is safe for existing track numbers. |
| 7 | Identity sources | AE MOGRT: `getMGTComponent().mogrtPath` = undefined; `projectItem` is SHARED by every instance of the same MOGRT (one project item "[라온올제] …" for 6 clips); `projectItem.getMediaPath()` = `…\Motion Graphics Template Media\<guid>\<name>.aegraphic`. Native Graphic clip: `projectItem` = null, `getMGTComponent()` = null, name "Graphic". | Project-item metadata cannot tag individual clips → clip name is the only per-clip tag. For natives nothing else identifies the template. |
| 14 | `importMGT` with trackIdx ≥ numTracks | NO error: the clip is silently placed on the LAST existing video track (tested idx = numTracks and numTracks+3). | Always ensure tracks exist BEFORE placement and verify the resulting clip's track. |
| 15 | Track lock API | `track.isLocked()` (function, returns bool) and `track.setLocked` exist. | Pre-check locked target tracks. |
| 5 | Set `end` past the next clip on the same track | Accepted: produces two OVERLAPPING clips on the same track (0~4 and 2~7). | Clamp end to the next clip's start (or route to another lane) — never extend blindly. |
| 6 | `trackItem.remove(false,false)` | Returns true. Stale reference still readable (name/start); removing it again returns false, no exception. | Removal is safe; re-validate before acting on cached refs. |
| 8 | Motion Position with keyframes | `setValue` returns true but keys stay (value at key time unchanged) → effectively ignored. `setTimeVarying(false)` clears keys and keeps the last set value. | Position writer must detect `isTimeVarying()` and skip/ask rather than silently fail. |
| 11 | Frame rate / snapping | `seq.getSettings().videoFrameRate.seconds` readable (0.0417 = 23.976). `importMGT` start snaps DOWN to a frame boundary (30s → 29.988s). | Compare times in frames (|Δ| ≤ 1 frame), not raw seconds. |
| 19 | Throughput | 5 × (importMGT + MGT text setValue + end + name) = 3.8 s → ~760 ms per clip. | 100 rows ≈ 76 s → chunk (e.g. 10–20 per evalScript) with progress + cancel. |
| 20 | rawValue stability | Two reads of the text property after setValue are byte-identical (AE capsule JSON, 332 chars). | Hash of rawValue is usable for "edited in Premiere" detection. |
| 22 | CEP runtime | Chromium 99, CEP 12.0.1, Node `require` enabled, `window.cep.fs` present; `TextDecoder('euc-kr')` and `'utf-16le'` work. | SRT encoding detection (UTF-8/BOM, UTF-16, CP949) is feasible in the panel. |
| — | Script `app.project.closeDocument` | Unloads the CEP panel (debug port disappears) → the rest of the script never returns; panel stayed blank until Premiere restart. Launching Premiere with a project path on the command line failed ("path does not exist", localized path). Opening via Ctrl+O worked. | Test automation must not close projects from the panel; restart Premiere and open the project via the Open dialog. |
| 16 | JSX reload | (Known from earlier session) hostscript.jsx is cached until Premiere restarts; all CEP extensions share one ExtendScript global scope (last loaded wins). MCPBridgeCEP is also installed and defines globals. | New JSX entry points must use a unique prefix (e.g. `MI_`); every JSX change needs a Premiere restart to test. |
| 23 | Native MOGRT with 2 text layers ("Lower Thirds/Classic Lower Third Two Lines.mogrt") | Clip has components Opacity, Motion, Vector Motion, **Text, Text**, Shape. `collectNativeTextProps` returns the two Source Text props in component order; setValue("FIELD_ZERO"/"FIELD_ONE") and readback by index work. Initial getValue returns odd single chars (e.g. "ƈ") before any write, so the template's default text cannot be read back. The `.mogrt`'s `definition.json` lists `clientControls` in Essential Graphics order with type 6 = TextLayer (here 0 "Insert Name Here", 1 "ADD TITLE HERE"). Visual confirmation of which component maps to which EG row was inconclusive (text not rendered at the probed frame). | For native templates, read field order/labels from `definition.json` (JSZip is already loaded in index.html) and assume component order == clientControls order of TextLayer entries; verify on the user's own native MOGRTs during stage 1 and fall back to "텍스트 N" labels if counts differ. |

Not measured (no script API or not needed now): Undo step count per apply (#9), per-preset natural durations (#12, measure during implementation), numeric key events (#10).

Open question for implementation: visually confirm native component order == Essential Graphics order on the user's own native MOGRTs (row 23).
